# Decision records

One file per decision: `YYYY-MM-DD-title.md`, the date it was made.

**Never edit a record after the fact.** If a decision changes, write a new record that supersedes it and say so in both.

Keep them short — this is a nine-day sprint. A record is worth writing when someone would otherwise re-litigate the choice, or when a teammate would be surprised by it.

```markdown
# Title, as a statement of what was decided

**Date:** 27 October 2026
**Decided by:** Furqaan
**Status:** Accepted

## Context
What forced a choice.

## Options
1. …
2. …

## Decision
What we are doing, and why this one.

## Consequences
What this costs us, and what it rules out.
```
